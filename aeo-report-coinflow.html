The finding
Across 372 opportunities to be named, Coinflow was named 13 times, most of them in a category not tested before: Ticketing Marketplaces.
Four independent grounded runs across ChatGPT, Perplexity, and Claude (Aug 31 to Sep 2, 2026), the expanded 31-question test run 4 times so far: 372 opportunities to name Coinflow. It was named 13 times. Nine of those came from the new Ticketing Marketplaces category, including two #1 rankings. Coinflow's own score moved by only 2 points across all 4 runs (9 to 11), a stable early read. Scalient IQ's standard is 5+ runs before a number is locked for external use; this is run 4 of 5, shown ahead of today's meeting because the number has held steady so far. Treat it as directional until the 5th run confirms it.

It hadn't yet measured Coinflow's own share of voice inside it, which is what this report does.

Gaming: the one lane that's open
Where Coinflow's 13 appearances came from
9 of 13 mentions, including 2 #1 rankings, from Ticketing Marketplaces
This is the standout change from the first test. Coinflow was ranked first by Claude on "What are the best payment infrastructure providers for ticketing and event marketplaces?", and first by Perplexity on "What are the best providers for instant seller payouts on ticket marketplace platforms?" The remaining mentions split between Marketplaces (2) and Gaming (2); Gaming's share shrank relative to the first test, where it was Coinflow's only lane. Stablecoin infrastructure, Coinflow's own category, remains untouched across all 4 runs.

What to do about it
This is a point-in-time baseline. The read is meant to run monthly, the same way it does for other Scalient IQ clients, so any content work gets held to a moving number.
  • Lean into ticketing marketplaces now, it's working. 9 of 13 mentions and 2 #1 rankings came from this one new category. That's a live signal worth content investment while it's fresh, not just a data point to file away.
  • Stablecoin infrastructure is still the biggest gap, and it's Coinflow's own category. Zero presence across all 4 runs, unchanged from the first test. Circle and BVNK are the vendors the engines currently reach for here.
  • Confirm the read with a 5th run before locking any number externally. Coinflow's own score has only moved 2 points across the 4 runs so far (9 to 11), a good sign, but Scalient IQ's standard is 5 runs minimum before a number goes external.
  • Watch the new agentic commerce and ISV categories going forward. No Coinflow mentions there yet in this round, worth tracking as those categories mature rather than a priority today.
